# WeLink Message Exporter

Windows desktop tool to export selected WeLink group or private conversations to UTF-8 TXT files.

## Features (v0.0.2)

- Categorize conversations into **All / Private / Group** and search locally.
- Discover conversations through recent chats and WeLink CLI person/group search. Manually add a `group_id` or private `target_account` for older conversations.
- Select one or multiple conversations, and set an **inclusive date range** (Beijing time, UTC+08:00).
- Fetch historical messages with message-ID pagination, de-duplicate and sort chronologically, including your own messages.
- Resolve senders' names and employee numbers when the contact API supplies them; otherwise preserve the sender account.
- Export TXT with original message line breaks; non-text messages retain their raw textual descriptors. The tool does not download attachments.
- Cancel operations, view progress/log messages, and safely discard incomplete export files.
- Fully dark date controls with a custom dark calendar popup; matching input, focus, selection and scrollbars.
- Interactive login starts the real `welink-cli auth login` command in a visible console, waits for mobile QR approval without an arbitrary timeout, verifies `auth status`, and refreshes conversations on successful login. Use **Cancel** to stop a pending login.
- Export diagnostic logs to `%LOCALAPPDATA%\WeLinkMessageExporter\logs` without message bodies or tokens.

## Requirements

- Windows 10/11 with .NET 8 SDK (for building).
- Node.js, WeLink PC and the authorized internal `@welink/welink-cli` installation.
- Sign in via `welink-cli auth login`. The app provides a **扫码登录** button that runs the same CLI QR flow in a separate console.
- The CLI executable and phone are not bundled with this application. The QR code is rendered by the official CLI, not generated by the exporter.
- Follow the WeLink and company data-handling rules for chat exports.

## Run and build

- `run_dev.bat` — build and run.
- `build_release.bat` — publish self-contained `win-x64` app to `publish/win-x64/`.
- `diagnose.bat` — check the local .NET / WeLink CLI installation and locate startup/crash logs.

On startup the app opens its window first, then checks CLI login status and refreshes conversations. Recoverable CLI errors are displayed without closing the window. Fatal startup and dispatcher exceptions are recorded to `%LOCALAPPDATA%\WeLinkMessageExporter\logs\startup-crash.log`. If that directory is inaccessible, the fallback is `%TEMP%\WeLinkMessageExporter-startup-crash.log`. No credentials or message bodies are intentionally written to these logs.

The distributed executable still calls `welink-cli.cmd` installed on the local computer. The included `login_auth.bat` must stay beside the built/published `.exe` (the project automatically copies it). It does not bundle credentials or WeLink CLI itself.

## Completeness and safety

WeLink CLI documents **recent conversations**, keyword searches and history queries, but not a global enumeration of every past conversation. Therefore no tool can truthfully promise exhaustive conversation discovery using only these interfaces. The list combines recent results, keyword searches, manually added chats and a local conversation index that persists between runs.

During history extraction, pagination continues towards older messages until the specified start date or history exhaustion. If the cursor or response format fails, the affected chat is marked failed instead of exporting a silently truncated TXT. Chat history visibility still depends on what the authenticated WeLink account/API can retrieve.

Conversation and resolved-contact indexes are stored under `%LOCALAPPDATA%\WeLinkMessageExporter`; message bodies are written only to the selected export directory. No chat messages are sent to third-party services.
